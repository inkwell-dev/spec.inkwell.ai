**§1.13 — the publishing pipeline (fixes 1.1, 1.9, 1.10, 1.11, 1.13 in one go).**
Several of these come from printing the PDF with Chromium, which cannot do TOC page
numbers, roman/arabic page numbering or automatic figure numbering. Two options:

- **A. pandoc → LaTeX (xelatex) → PDF.** The academic standard: TOC with page numbers
  to any depth, roman/arabic numbering, automatic lists of figures and tables,
  centred captions, and **numbered citations from a `.bib` file**, which also solves
  his priority 1 cleanly. It runs in a Docker image (`pandoc/extra` or a TeX Live
  image). The cost is about 1–2 hours to set up the layout once.
- **B. Paged.js in Chromium.** Keeps the current HTML/CSS but adds a paged-media
  polyfill (TOC page numbers via `target-counter`, roman/arabic page counters).
  Lighter, but citations and figure numbering remain hand-rolled.

**Recommendation: A**, unless TEK-UP's template is a Word file. In that case the
Word output should become the reference instead, and pandoc can use the template as
`--reference-doc`.
